一个 Windows 10/11 x64 原生桌面工具。用户手动刷新后，软件展示四个独立榜单：**基本面消息**（同花顺公开新闻 + 巨潮资讯全市场公告）、**基本面互动**（深交所互动易 + 上证 e 互动的官方问答代理指标）、**综合人气**与**飙升榜**（东方财富官方榜单）。数据零配置、手动刷新、公开发布，只读取全市场信息流，不逐只股票抓帖。

> 热度统计仅用于信息整理，不构成任何投资建议。

## 功能

- PySide6 原生桌面界面，不启动浏览器或本地 Web 服务。
- 顶部四个标签：**基本面消息**、**基本面互动**、**综合人气**、**飙升榜**，各自独立统计、筛选和查看明细。
- 基本面消息榜：同花顺公司资讯、个股聚焦、公司研究、行业研究、证券市场新闻、独家公司互动、个股公告栏目，加上已实际接入的巨潮资讯公告/调研流、上交所与北交所公司公告流、上证 e 互动发布及北交所业绩说明会流。公告与调研附件（PDF、DOC、DOCX）会下载并在本地临时目录提取正文后立即删除，正文用于后续研究信号；空文本、加密、损坏或下载失败的附件保留原文链接并标记 `empty_text`/`failed` 状态，不伪造正文。
- 基本面互动榜：深交所互动易与上证 e 互动的全市场最新问答流；**只有公司已回复的提问才计为有效提问，提问的统计时间定义为回复时间**，未回复提问不计入榜单；界面明确标注为“官方问答代理指标”（仅覆盖沪深市场，北交所未纳入本版所选官方问答平台）。
- 研究来源渐进回填：每次刷新在完成当前窗口榜单后，用受控配额（最多 40 个列表页或 100 份新附件）向前回填最近 200 个自然日的研究来源历史（巨潮公告/调研、上证 e 互动“上市公司发布”、上交所公司公告、北交所公司公告与业绩说明会）。页数和附件额度在来源间均分，公告流不会挤占调研来源；每个完整列表页与游标在同一事务中提交，刷新取消或失败后保留已提交页面，下次从游标继续且不重复下载已完成文档。
- 研究信号（1.1.0 新增）：在保留原始四榜之外，提供**确定性利好**、**潜在催化**、**20 日机构升温**与 **60/120 日持续关注**四个研究视图。短期引擎对十类固定事件类型做规则抽取，判断事件是否可能改变收入、利润、资产、订单、监管状态或资本结构；机构引擎统计公开披露的调研/投资者关系参与行为（独立机构集团数、活跃周、重复跟进、问答深度与单日集中度）。每个入榜信号都可追溯到证据摘录与原文链接，`no_valid_signal` 是正常且高频的结果，产品不强迫每条信息生成利好。
- 东方财富端低频读取官方公开的 A 股人气榜 Top 100 与飙升榜 Top 100；官方只公布排名与较昨日变动，权重未公开，软件不重算热度值，也不合成主观总分。
- 过滤融资余额、ETF 资金、固定格式资金流、股东户数和批量机构调研等模板稿，以及会议通知、独立董事意见、中介机构程序性文件等高置信度例行公告；每条过滤都保留明确原因。
- 对跨栏目重复 URL 和高相似事件去重（同一股票、6 小时内、规范化标题相似度不低于 90% 的跨来源报道合并为同一事件），一件事对同一股票最多计一次。
- 互动记录按平台问答 ID 去重，同一股票 24 小时内（按回复时间）完全相同的规范化问题再次去重；仅过滤空内容、非 A 股、明显垃圾内容，以及“纯走势/庄家/盘口”且没有经营、财务、治理或重大事项语义的问题。
- 排名可搜索、排序；点击股票名称可查看合并事件下的全部支撑来源（含巨潮公告原文链接）或互动问答原文，或打开东方财富官方个股人气页。
- SQLite 缓存与快照存放在 `%LOCALAPPDATA%\AshareHotPot`，升级安装不会覆盖。
- 观察窗口同时影响基本面消息榜与基本面互动榜（1–168 小时，默认 24 小时）；官方人气榜显示截至读取时间，不暗示对应某小时窗口。
- 新增来源成功结果缓存 10 分钟并设置最大分页数；任何来源读取失败、沿用本地缓存或未到达窗口边界，都会在“数据质量”区域明确标注部分覆盖与过期状态；全部来源失败时不会产生伪空榜。
- 可选 AI 增强默认关闭：开启后仅向模型发送规则初筛后的事件代表文本，输出经严格 JSON/枚举/范围校验，模型故障只降级当前事件（界面显示“规则降级”），不影响整榜；密钥使用 Windows DPAPI 加密保存，不写入数据库、日志、导出或剪贴板。

## 研究信号（1.1.0）

研究信号与原始四榜相互独立，不合成统一总分，也不表达任何看多、买入或资金流向含义：

- **确定性利好**：有证据支持的正向机制，重大性等级 ≥2、确定性 ≥0.70、无高度反证，得分 ≥60。
- **潜在催化**：有正向机制、重大性 ≥1、确定性 ≥0.40、无标题正文冲突，得分 ≥35，卡片始终标注“尚未落地”。
- **20 日机构升温**：最近 20 个交易日相对前五个 20 日分桶基线（共 120 个交易日）的机构集团关注加速 `z20=(当前-均值)/max(标准差,1)`；覆盖不足时显示冷启动并保留原始指标。
- **60/120 日持续关注**：持续关注分 = 100 × (0.40×活跃周比例 + 0.25×重复跟进比例 + 0.20×研究深度 + 0.15×(1−单日集中度))；120 日视图额外比较最近 60 日与此前 60 日的研究行为结构变化。

短期事件先按同一股票、72 小时内的高置信规则做持久化聚类（金额/客户/日期冲突时宁拆不并），超过 72 小时但 180 天内的高度相似事件只建立历史关联；金额、比例、客户、状态等字段只取正文显式值，缺失即返回空值，不根据常识补全。机构实体按保守归一与集团归并计算，模糊相似只标记待核，不自动合并。

## 本地开发

需要 Python 3.11 或更高版本（推荐 3.12）。

```powershell
python -m pip install -e ".[dev]"
python -m pytest
python -m ashare_hotpot
```

也可以运行：

```powershell
.\scripts\run.ps1
```

如需把数据写到项目内的临时目录，可在启动前设置：

```powershell
$env:ASHARE_HOTPOT_DATA_DIR = "$PWD\data"
python -m ashare_hotpot
```

## Windows 构建

生成 PyInstaller `onedir` 目录：

```powershell
.\scripts\build.ps1 -SkipInstaller
```

如果本机 PowerShell 禁止直接运行脚本，可使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -SkipInstaller
```

输出位于 `dist\AshareHotPot\AshareHotPot.exe`。生成标准安装包还需要安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)：

```powershell
.\scripts\build.ps1
```

安装包输出到 `dist\installer`。安装按当前用户进行，默认不需要管理员权限。第一版没有代码签名，Windows SmartScreen 可能在首次运行时显示提示。

## 测试

```powershell
python -m pytest
```

默认测试完全离线。若要小规模验证当前同花顺、巨潮资讯（公告/调研）、互动易、上证 e 互动（问答/发布）和东方财富的线上结构，可显式运行：

```powershell
$env:ASHARE_HOTPOT_LIVE_TEST = "1"
python -m pytest -m live
```

## 数据口径与限制

- 统计窗口由界面的“消息窗口”选择器决定，同时作用于基本面消息榜与基本面互动榜，范围为 1–168 小时，默认 24 小时。
- 基本面消息榜按有效事件数降序 → 最近事件时间降序 → 股票代码升序排列；原始篇数和来源数只用于解释，不参与加权。基本面互动榜只统计已回复提问（统计时间为回复时间），按有效提问数降序 → 最近回复时间降序 → 股票代码升序排列。
- 东方财富官方榜按官方公布排名展示（人气榜为综合关注度名次，飙升榜为较昨日排名提升最多的股票），并列时按官方返回顺序。
- 按东方财富公开口径，综合人气由访问、关注和社区互动共同构成（[榜单规则](https://gbcdn.dfcfw.com/rank/)）；软件不展示或推导任何未公开的热度数值。
- 纳入沪深北交易所 A 股及 ST 股票，排除 B 股、基金、债券、指数、概念和港美股。
- 基本面互动是官方公司问答的代理指标，不是严格意义上的全网语义统计；北交所因未纳入本版所选官方问答平台，互动榜只覆盖沪深市场。互动榜只统计公司已回复的提问，窗口按回复时间计；提问时间早于窗口但刚被回复的问答会进入榜单，未回复的提问不会出现。
- 同花顺列表公开分页有限；巨潮公告、互动易与上证 e 互动按全市场信息流分页读取并受最大分页数限制。软件会结合本地缓存，但手动刷新间隔过长或来源未到达窗口边界时仍可能存在遗漏，并会在界面明确标注。
- 东方财富官方综合人气仅作为散户整体关注度的代理，不能解释为情绪、资金流向或交易建议；其热度权重未公开，软件不进行可复算的推测。
- 研究信号只描述公开披露的新事件与机构调研参与行为，不预测股价、不输出买卖建议；机构关注不代表看多、买入、持仓或资金流向。所有结论必须有正文依据，缺少依据时返回空值或无信号。
- 机构指标的 20 日 z-score 需要完整 120 个交易日覆盖，不足时返回空值并显示冷启动；行业分位数在样本不足 5 只时同样返回空值。
- 抓取器使用有限并发、请求间隔和失败重试；请勿改造成高频或商业化采集器，正式分发前应自行核对来源站点的使用条款。

## 项目结构

- `src/ashare_hotpot/`：采集、解析、过滤、去重、SQLite、Qt 界面和后台线程。
- `tests/`：离线解析、排名、存储、刷新流程和 Qt 工作线程测试。
- `ashare_hotpot.spec`：PyInstaller `onedir` 配置。
- `installer/AshareHotPot.iss`：Inno Setup 当前用户安装包配置。
# Codex CLI + DeepSeek

在项目根目录运行（推荐；不受 PowerShell 执行策略影响）：

```powershell
.\start_codex_deepseek.cmd
```

也可以双击该 `.cmd` 文件。若本机 PowerShell 已允许执行本地脚本，也可以运行：

```powershell
.\start_codex_deepseek.ps1
```

脚本使用项目内的 Codex CLI、独立的 DeepSeek 配置和 `deepseek-v4-flash`。如果当前终端没有
`DEEPSEEK_API_KEY`，启动时会以隐藏输入提示 API key；密钥只在该次启动期间保留，不会写入仓库或用户配置。

如需在当前 PowerShell 会话中预先设置密钥，可以运行：

```powershell
$env:DEEPSEEK_API_KEY = "sk-你的 DeepSeek API Key"
.\start_codex_deepseek.ps1
```

首次克隆项目但没有本地 Codex CLI 时，执行一次：

```powershell
Push-Location .codex-cli
npm install
Pop-Location
```

本配置只使用 DeepSeek 原生支持 Codex Responses API 的 `deepseek-v4-flash`，不改动用户全局的 Codex 配置。
